Tile asset contract

Preferred runtime format: PNG
Path: public/tiles/png/<tileId>.png

Fallback/dev format: SVG
Path: public/tiles/svg/<tileId>.svg

Tile ids:
- chi
- 2_van, 2_vanh, 2_sach
- ...
- 9_van, 9_vanh, 9_sach

To replace with your own art, overwrite the PNG files with the same filenames.
